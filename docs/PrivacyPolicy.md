# プライバシーポリシー

bannzai（以下「提供者」といいます。）は、提供者の提供する Chrome 拡張機能「Web Full Screen Capture」（以下「本サービス」といいます。）における利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

## 収集する利用者情報

本サービスは、ユーザーの個人情報および利用者情報を収集しません。

- 本サービスは、ユーザーが撮影を指示したタブの表示内容をブラウザ内でのみ画像化し、ユーザーのダウンロードフォルダに保存します。撮影した画像、ページの内容、URL、タイトルが外部に送信されることはありません
- 本サービスは、サーバー、アカウント、アクセス解析・行動計測の仕組みを持ちません
- 本サービスは、ブラウザのストレージに設定や履歴を保存しません

## 権限の利用目的

本サービスが利用するブラウザの権限と、その利用目的は以下のとおりです。

- `activeTab`: ユーザーが拡張機能のアイコンをクリックしたタブの表示内容を撮影するため。クリックしたタブ以外のページにはアクセスしません
- `scripting`: 撮影対象のタブをスクロールして、ページ全体を分割して撮影するため
- `downloads`: 撮影した画像をユーザーのダウンロードフォルダに保存するため

## 第三者提供

本サービスは利用者情報を収集しないため、第三者（日本国外にある者を含みます。）への提供は行いません。

## プライバシーポリシーの変更手続

提供者は、必要に応じて、本ポリシーを変更します。変更後の本ポリシーは、本サイトに掲載された時点から効力を生じるものとします。
