ページ全体を 1 枚に

開いている Web ページを、画面に収まらない部分まで含めて 1 枚の PNG に保存する Chrome 拡張機能。
ボタンを押すだけで自動でスクロールしながら撮影し、ダウンロードフォルダに保存します。

画面の外

使い方は 3 ステップ

面倒な設定はありません

1

保存したいページを開く

記事、ドキュメント、ダッシュボードなど、Chrome で開いているページならどれでも対象です。

2

拡張のアイコンをクリック

ツールバーのアイコンから「撮影して PNG を保存」を押します。あとは自動で下までスクロールしながら撮影します。

3

ダウンロードフォルダを開く

ページのタイトルと日時が付いた PNG が保存されます。撮影後はスクロール位置も元に戻ります。

必要なことだけを、ブラウザの中で

サーバーもアカウントもありません

🖼

ページ全体を 1 枚の PNG に

画面に収まらない縦長のページも、分割して撮影した画像をつなぎ合わせて 1 枚にします。Retina などの高解像度ディスプレイにも対応します。

📌

固定ヘッダーの重複を抑える

スクロールしても付いてくる固定ヘッダーやバナーは、先頭の 1 回だけ写して以降は隠します。

🔒

データは外部に送信しない

撮影も保存もブラウザ内で完結します。ページの内容や画像がサーバーに送られることはなく、アクセス解析も含みません。

✅

最小限の権限

アクセスするのは、あなたがアイコンをクリックしたタブだけ。すべてのサイトを常時読み取る権限は要求しません。

長いページも、そのまま残そう

Chrome ウェブストアでの公開準備中です。公開までお待ちください。
